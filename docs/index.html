Picture Elicitation · 看图发音词卡

面对高龄或不识字发音人，避免书面字面诱导地道口语词

调查「太阳 / 日头」「衣服 / 衣裳」「水桶 / 吊桶」等日常核心词时，直接展示汉字往往会诱使发音人读出文读字音或普通话词汇。PhonAcq 支持按需配图、文件名批量建词及看读页独立显隐汉字。

示例词卡：

按文件名一键批量建词与配图

准备一组形如 01_日头_太阳.jpg、02_衣裳_衣服.png 的图片，即可一次性自动生成带序号、词目与备注的调查表，未配图词条依然按常规文字展示。

独立显隐汉字，杜绝字面干扰

在录音台或无线看读端点击顶栏「看读」设置，可随时隐藏目标汉字与词表释义，只向发音人呈现干净大图；调查人手持端仍完整显示记音提示与目标音标。

无级缩放局部细节 + 导出包随行备份

配图区域支持双指捏合放大至 4 倍并拖动平移，方便指认农具、服饰构件或动植物局部；打包导出时可选将词卡图片随 images/ 目录完整归档并支持无损导回。

Offline LAN Dual-Device Sync · 双机无线联动

零互联网田野现场：一台平板给长辈看字，一台手机在手边静默遥控

两台设备只需连入同一手机热点或路由器，输入六位配对码即可直连。支持远程切词、随机打乱顺序（防顺序效应）、护眼宣纸/墨水屏/黑板切换、中场茶歇屏以及无线实时耳返监听。
